# Разработка

main содержит рабочий код, спецификации и инструкции. Эксперименты, результаты
замеров и исследовательские планы ведутся в discover. Публикация main не означает
закрытие всех критериев приёмки: ограничения перечислены в README.

## Установка и тесты

```bash
python -m venv .venv
# Активируйте окружение или используйте полный путь к его Python.
python -m pip install ".[sender,receiver,fec,qr]"
python -m unittest discover -s tests -q
```

Проверяйте Python 3.10 и 3.12. Дополнительные зависимости устанавливаются явно:
базовый пакет не требует библиотек захвата на отправителе. tools/i00.py и
 diagnostics/browser используются регрессионными тестами диагностики; старые
 code.py/qr.py оставлены как совместимые исходники прототипа AQR1.

```bash
python -m pip install build
python -m build --wheel
```

Пакет должен включать assets/player.html и assets/player.js. После установки wheel
проверяйте `python -m qr_transfer --help` вне каталога исходников. Реальные измерения
VDI фиксируйте отдельно от локальных тестов, с разрешением, интервалом, транспортом,
цветом, полным восстановлением и версией кода.

Ближайшая техническая задача — установить причину падения крупного LT-приёма.
Журнал успешно восстанавливается локально; это не доказывает исправление сбоя.
Диагностика должна сохранять тип и место ошибки без содержимого пакетов и паролей.
