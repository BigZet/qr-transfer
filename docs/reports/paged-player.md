# Порционная загрузка: локальные проверки 0.6.1

Реализована загрузка отдельных CRC-проверяемых порций через обычный HTTP GET.
[Спецификация](../specs/paged-player.md) · [Тест на VDI](../usage/paged-vdi-test.md).

## Сквозная проверка

[JSON](../../benchmarks/paged-player/local.json). Синтетический исходник 128 КиБ,
парольный архив, RGB8/2 QR, 150 мс, headless Chrome Full HD, локальный HTTP.
Порции по 8 матриц специально малы, чтобы часто пересекать границы.
Repeat и LT завершили приём, SHA-256 и распакованные байты совпали.

В каждом прогоне плеер затем прошёл все порции, новый цикл и смену моно/4/8 цветов.
Кэш не превысил четыре готовые порции; максимум учтённых буферов матриц —
**160 597 байт**, включая загружаемую порцию и копию metadata. Никаких запросов
полного `frames.bin` или внешнего JavaScript. Число запросов при старте меньше
общего числа порций.

## Большой набор и ошибки

[JSON](../../benchmarks/paged-player/faults-and-large-load.json).
Нагрузочный набор **134 216 017 байт** матриц разбит по 256 штук. При старте
загружено **1 002 752 байта**, готовность наступила примерно за **0,17 с** на
локальном HTTP. Полный файл в браузер не загружался. Набор содержит повторную
валидную матрицу: это проверка загрузки большого объёма, не передачи большого
архива целиком.

Задержка следующей порции остановила продвижение курсора; число обновлений
оставалось неизменным. Повреждённая порция отклонена по CRC, показ остановлен.
После восстановления и Старт приём данных плеером продолжился с тем же ID.
Отсутствующая начальная порция отображает HTTP 404 на странице.

## Регрессия и оценка времени

**91 тест** прошёл на Windows/Python 3.10.21 и 3.12.10. Проверены разбиение и
точная сборка матриц, CRC/размеры, обновление HTML с сохранением ID и отказ при
повреждённом исходнике. Текущий standalone запускается без внешних порций.
Wheel 0.6.1 установлен и CLI проверен вне исходников на Python 3.10.

Видимая оценка времени пересчитывается при изменении интервала, числа слотов,
цвета и sync/staggered. Старые измеренные интервалы при такой смене сбрасываются.
Проверено сохранение читаемой строки в fullscreen без перекрытия QR и образцов.
Оценка относится к полному циклу, не к подтверждённому завершению хоста.

## Открытая проверка

После теста пользователя подтверждено точное восстановление 10 МиБ через
RGB8/repeat с захватом 4K: [отчёт VDI](vdi-paged.md). Параметры порций и раннего
старта требуют отчёта отправителя. Сценарий 32 МиБ остаётся непроверенным.
Скорость QR-канала, время полной генерации и память всего браузера требуют
отдельных измерений; ограничение кэша матриц не является ограничением RSS.
