# И02: парольный архив и восстановление

[Спецификация контейнера](../specs/container.md) · [Локальные проверки](../reports/container.md)

Работа выполняется в терминале, notebook не требуется. Пароль вводится скрыто,
без параметра CLI. Этот этап проверяет файлы на диске; новый браузерный плеер — И03.

## Установка

В выбранном окружении Python 3.10/3.12 из корня репозитория:

```bash
python -m pip install ".[container]"
```

Используется настроенный источник pip. Закреплён `py7zr==1.1.3`.
[Проверенные версии зависимостей](../../requirements/i02-tested.txt) — снимок
локального Windows-окружения; их наличие во внутреннем зеркале пока не подтверждено.

## 1. Подготовить файл или каталог на отправителе

```bash
python -m qr_transfer pack artifacts/i00/fixtures/tree --output artifacts/i02/prepared
```

Введите пароль и повторите его. Выходной каталог должен быть новым. Получатся:

- `object.7z` — зашифрованный архив со скрытыми именами;
- `descriptor.json` — только технические параметры, размер и SHA-256 архива.

По умолчанию используется `--profile max`. Для меньших затрат попробуйте `strong`;
`ultra` доступен для сравнения с большим словарём. Максимальный словарь не гарантирует
меньший архив. Исходные ссылки и специальные файлы отклоняются; скрытые файлы и
`.git` включаются, если лежат в выбранном дереве. Изменение исходника во время
подготовки даёт `source_changed`: остановите запись в него и повторите в новый выход.

Пароль и исходные имена не входят в descriptor. Повторный показ использует готовый
архив, повторно запускать `pack` не нужно.

## 2. Локально проверить цепочку с AQR2

```bash
python -m qr_transfer prepare artifacts/i02/prepared/object.7z --descriptor artifacts/i02/prepared/descriptor.json --output artifacts/i02/encrypted.aqs --cycles 3
python -m qr_transfer receive artifacts/i02/encrypted.aqs --state artifacts/i02/received
```

Здесь `.aqs` подаётся приёмнику с диска — это локальная проверка, не передача через
VDI. В отличие от тестового режима И01, `--descriptor` проверяет архив и помечает
metadata как `7z-aes256`. Пароль на стадии пакетизации/приёма не требуется.

## 3. Проверить и распаковать на приёмнике

```bash
python -m qr_transfer inspect-container artifacts/i02/received/object.bin --descriptor artifacts/i02/received/status.json
python -m qr_transfer unpack artifacts/i02/received/object.bin --descriptor artifacts/i02/received/status.json --output artifacts/i02/restored
```

`status.json` содержит согласованный транспортный дескриптор. Для прямой локальной
проверки вместо принятого объекта можно указать `prepared/object.7z` и
`prepared/descriptor.json`. Размер и SHA-256 проверяются **до запроса пароля**.

На ввод пароля предоставляются три попытки (`--attempts`). Сообщение «неверный пароль
или повреждённый контейнер» намеренно не утверждает точную причину. После ошибки
архив сохраняется; команду `unpack` можно повторить, новая передача не нужна.
Готовый результат публикуется только после проверки манифеста. Существующий выход
не перезаписывается — выберите другое имя. При успехе stdout содержит `state=complete`.

В `restored` появится исходный файл или каталог с исходным именем. Права/ACL и даты
не входят в гарантию восстановления. Если в дереве недопустимые для Windows имена
или коллизии регистра/Unicode, подготовка/распаковка завершится ошибкой без
молчаливого изменения имён.

## Проверки и измерения

```bash
python -m unittest discover -s tests -v
python tools/check_i02_container.py --output artifacts/i02/benchmark
```

Тесты используют синтетический пароль внутри тестового кода. Benchmark создаёт
синтетические исходники, сравнивает три профиля и проверяет каждый распаковкой.
Подробности и границы памяти приведены в отчёте; профиль max на больших данных
может работать заметно дольше strong.

Локально проверены Windows/Python 3.10 и 3.12. На JupyterHub остаётся проверить
установку из зеркала, скрытый ввод в терминале, подготовку на Linux и реальную RAM.
При нехватке места или отмене готовый результат не объявляется; исходник и уже
принятый зашифрованный объект сохраняются. Пустой каталог неуспешного `pack` может
остаться — для нового прогона выберите новый выход.
