# И06: экспериментальные цветные QR

[Спецификация](../specs/rgb-qr.md) · [Локальные результаты](../reports/rgb-qr.md).

4 цвета передают два пакета в одном QR, 8 цветов — три. Это число слоёв, а не
гарантированный множитель скорости. На вашем VDI цвет ещё нужно проверить.
Моно остаётся штатным резервным режимом. Python 3.10 поддерживается.

## Подготовка в JupyterHub

```bash
python -m pip install ".[sender,fec]"
python -m qr_transfer render artifacts/i03/prepared/object.7z --descriptor artifacts/i03/prepared/descriptor.json --output artifacts/i06/player --transport lt --visual rgb8 --slots 1 --interval-ms 600
```

Можно взять тот же парольный архив, который проверяли в И03/И05. Новый `render`
создаёт новый ID передачи. Откройте `artifacts/i06/player/standalone.html` отдельной
вкладкой через `/files/`, включите полный экран. Верхний отступ под панель VDI
сохраняется. В цветном режиме под каждым QR должна быть видна вся полоска образцов.

Для repeat замените `--transport lt` на `--transport repeat`; для четырёх цветов —
`--visual rg4`. Два QR: `--slots 2`. На том же плеере можно менять эти визуальные
настройки: данные не пересоздаются, ID сохраняется. После смены цвета плеер на паузе.
Транспорт выбирается при `render` и в процессе показа не меняется.

## Приём на Windows, монитор 1

```powershell
.\.venv-i00\Scripts\python.exe -m pip install ".[receiver,fec]"
.\.venv-i00\Scripts\python.exe -m qr_transfer capture --transport lt --visual rgb8 --monitor 1 --state artifacts/i06/vdi-1 --extract-to artifacts/i06/restored-1
```

Запустите приёмник, затем **Старт** в браузере. Профиль цвета и транспорт на обеих
сторонах должны совпадать. `--visual rg4` принимает две плоскости R/G, `rgb8` — R/G/B.
`--visual mono` использует прежний моно-декодер. Для цветного декодера дополнительно
устанавливается NumPy; на отправителе он не нужен.

Приёмник по умолчанию классифицирует центральные пиксели модулей по цветовым
образцам (`--color-method palette`). Образцы перечитываются на каждом кадре.
Периодический служебный QR помогает найти область после позднего старта или
перемещения. Кнопка **Калибровка** останавливает показ и выводит служебные QR
с образцами; затем нажмите **Старт**. Отдельно сохранять калибровку не требуется.

Контрольный вариант `--color-method threshold` использует независимые пороги 128
и не требует цветовой полоски для разделения каналов. Сравните оба метода, если
режим с палитрой не принимает данные. Если цвет нестабилен, уменьшите число цветов,
замедлите показ или вернитесь к моно. Автоматического переключения нет.

## Продолжение и смена цветового режима

Остановите приёмник, выберите нужный цвет в плеере, затем продолжите с тем же
каталогом состояния и тем же транспортом:

```powershell
.\.venv-i00\Scripts\python.exe -m qr_transfer capture --transport lt --visual rg4 --monitor 1 --state artifacts/i06/vdi-1 --resume
```

Файлы, уже распакованные в существующий каталог, повторно туда не распаковываются.
Для новой распаковки используйте новый путь. Для нового `render` нужен новый
каталог состояния. Пакеты repeat и LT не смешиваются.

## Что сохранить для проверки

- До повторного `--resume` сохраните копии `capture.json`, `status.json`,
  `extraction.json`: повторный запуск перезаписывает последние отчёты.
- Сохраните JSON плеера, разрешение VDI, масштаб и способ открытия страницы.
- В `capture.json`: `layers["слот:слой"]`, принятые/невалидные/повторные пакеты,
  `accepted_payload_bytes`, `decoder`, время и итоговый SHA-256.
- `accepted_payload_bytes` считает принятые payload символов, включая LT repair;
  это не скорость исходного файла. `restored_bytes_delta` при LT относится к слою,
  чей пакет завершил блок, а восстановление могло использовать все три слоя.
- `decoder.calibration_missing/rejected` — проблемы с видимостью/различимостью
  образцов. `layer_N_attempts/symbols/decode_seconds` — работа отдельных слоёв.

Начните с малого архива и одного QR, 600 мс. Затем на одном архиве сравните моно,
4/8 цветов и один/два QR. Восстановите файлы и проверьте хеши. Измерения 1/10 МиБ
и три повтора нужны до выбора рабочего профиля VDI. При ROI захватите QR целиком,
включая тихие зоны и полоску калибровки. Геометрия предполагается прямоугольной,
без поворота и перспективы, как при снимке экрана.

Опция `--skip-unchanged` пропускает повторное декодирование успешно прочитанного
неизменившегося слоя. По умолчанию выключена; сравнивайте на своих кадрах. Поиск
геометрии раз в секунду сбрасывает этот небольшой кэш. Очередь снимков по-прежнему
ограничена двумя, число сохранённых отпечатков — шестью.

## Локальное воспроизведение

```powershell
.\.venv-i00\Scripts\python.exe tools/check_i06_rgb.py --output artifacts/i06/local-new
```

Нужны extras `sender,receiver,fec`, Playwright и Chrome. Стенд создаёт собственный
синтетический файл и парольный архив, проверяет 12 комбинаций, потерю синего слоя
и кэш. Пароль стенда относится только к его синтетическим данным.

Для воспроизведения проверок масштаба после основного стенда:

```powershell
.\.venv-i00\Scripts\python.exe tools/check_i06_rgb.py --geometry-player artifacts/i06/local-new/player-repeat/standalone.html --output artifacts/i06/geometry-new
```
