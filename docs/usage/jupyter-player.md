# Плеер не загружает порции через /files/

Отдельная вкладка не гарантирует доступ HTML к соседним файлам. В Jupyter Server
[AuthenticatedFileHandler](https://github.com/jupyter-server/jupyter_server/blob/main/jupyter_server/base/handlers.py)
может выдавать HTML с CSP `sandbox allow-scripts`: скрипт выполняется, но получает
изолированный origin. Это вероятное объяснение скриншотов VDI; заголовки именно
того сервера пока не получены. Обновлённый плеер показывает origin=null явно.

## Запуск готового плеера

Обновите репозиторий. В отдельном терминале JupyterHub, из корня проекта:

```bash
python tools/serve_player.py artifacts/paged-vdi/player2 --port 8765
```

Скрипт напечатает путь вида `/user/<user>/<server>/proxy/8765/index.html`.
Откройте этот путь **на том же домене и порту JupyterHub**, отдельной вкладкой.
Длинный путь `/files/share/...` и параметр `_xsrf` из прежнего URL не нужны.
Терминал оставьте работающим. Ctrl+C останавливает сервер. QR повторно не
генерируются, transfer ID и состояние приёмника сохраняются. Для live оставьте
также работающим терминал генератора.

Сервер слушает только 127.0.0.1, обслуживает выбранный каталог, не выдаёт список
файлов и запрещает выход через символьные ссылки за его пределы. Новый пакет
для самого скрипта не нужен. Защиты Jupyter/CSP не отключаются.

Маршрут требует включённого **jupyter-server-proxy в работающем сервере Jupyter**:
[официальное описание](https://jupyter-server-proxy.readthedocs.io/en/latest/arbitrary-ports-hosts.html).
Если получаете 404, проверьте точный префикс и наличие расширения; установка
библиотеки только в .venv отправителя не включает её в сервере. 502/503 может
означать, что процесс не запущен или порт не совпадает. Доступность этого маршрута
на реальном VDI пока не подтверждена. Не открывайте 127.0.0.1 в браузере Windows:
JupyterHub может работать на другой машине.

## Диагностика без консоли браузера

После полного завершения render можно обновить HTML без генерации QR:

```bash
python tools/refresh_player.py artifacts/paged-vdi/player2
```

Затем Ctrl+Shift+R. При изоляции появится явное сообщение origin=null; поле
opaque_origin также доступно в «Отчёт и геометрия». Если причина другая,
сохраните текст сообщения и отчёт. Обновлять live HTML до завершения render нельзя.

Локальная проверка с настоящим CSP-заголовком воспроизвела изоляцию; через
обычный HTTP тот же порционный плеер готов, встроенный standalone работает
также при изоляции. Это проверка браузера, не установленного на VDI proxy.

```powershell
.\.venv-i00\Scripts\python.exe tools/check_player_sandbox.py artifacts/generation/wheel-check artifacts/generation/sandbox-new
```
