# Контрольный стенд И00

[Инструкция запуска](../../docs/usage/iteration-00.md) · [Отчёт о локальной среде](../../docs/reports/environment.md)

Генератор и runner: [`tools/i00.py`](../../tools/i00.py). Набор `qr-transfer-i00-v1` создаёт 64–256 КиБ воспроизводимых бинарных данных и дерево с Unicode/пустыми файлами и каталогами. SHA-256-последовательность не зависит от версии генератора случайных чисел Python.

Контрольные параметры: AQR1, V40-L, 2800 байт/чанк, 600 мс, PNG 1110×1110. Существующие `code.py` и `qr.py` используются без изменений.

Уровни доказательств в JSON:

- `environment_only`: версии, ресурсы и отдельный тест захвата; нет передачи.
- `legacy_preparation_only`: запуск генератора; нет приёма через экран.
- `synthetic_png_roundtrip_no_browser_no_vdi`: декодирование PNG из созданного HTML.
- `headless_local_browser_no_vdi`: декодирование снимков браузера, без VDI; пошаговый показ.
- `local_screen` / `real_vdi`: уровень, явно указанный оператором при запуске настоящего `qr.py` через `receive`.

Исходные локальные отчёты находятся в `artifacts/i00/` и не включаются в Git. Здесь сохраняются только небольшие отчёты синтетических прогонов, пригодные для распространения. Машинные пути, изображения рабочего стола и рабочие данные в опубликованные результаты не включать.

Пиковая память — дискретно измеренная сумма RSS дерева запущенных процессов. Это учитывает дочерний Python Windows venv launcher, но общие страницы могут учитываться несколько раз. При отсутствии `psutil` поле равно `null`, а не нулю.
